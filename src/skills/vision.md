# 图片 / 视觉输入技能（Vision / OCR）

当任务要求读取图片、识别图中文字（OCR）、描述图片内容或进行视觉分析时，按以下步骤执行：

## 步骤

1. **定位图片文件**：任务指令中带 `【图片】<路径>` 标记的，直接使用该路径；否则用
   `find`/`ls` 在工作目录内定位图片文件（常见扩展名：png / jpg / jpeg / webp / gif / bmp）。
2. **读取图片**：使用 `read` 工具读取图片文件（例如 `read <图片路径>`）。
   - 若当前模型支持图片输入（模型定义 `input` 含 `image`），图片会作为附件随 read 结果
     直接传给模型——**请直接基于图片回答**（描述画面、识别文字等）。
   - 若 read 结果中出现 `The image will be omitted` 之类的提示，说明当前模型不支持视觉输入，
     此时不要假装看到图片，按第 3 步处理。
3. **模型不支持视觉时的兜底（OCR）**：
   - 优先尝试系统 OCR 工具：`tesseract <图片> stdout -l chi_sim+eng`（若已安装）；
   - 或尝试 Python 方案：`python3 -c "from PIL import Image; print(Image.open('<路径>').size)"`
     至少获取图片尺寸/格式等可确定的元信息；
   - 明确向用户说明：当前模型不支持视觉，无法直接“看图”，并给出已获得的元信息。
4. **输出要求**：结果应包含——图片路径、识别/描述结果（或不可用说明）、所用方式（视觉模型 / OCR / 元信息）。

## 注意

- 图片可能位于工作目录或任务临时工作空间，先 `ls`/`find` 确认路径再读取；
- 不要编造图片内容；无法看到时应如实说明。
